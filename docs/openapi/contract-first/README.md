# Contract-first specs (superseded)

These OpenAPI files were written by hand in Sprint 6, before the endpoints were built. They describe the API as it was designed, not as it was implemented, and have drifted from the code. For example, they point at `localhost:8080` without the `/api` context path, most paths lack the `/v1` prefix (`/orders` rather than `/api/v1/orders`), and they include endpoints that were never built, such as `/accounts/{accountId}/exists`.

They are kept for reference only. Do not generate clients from them.

| File | Covered |
|------|---------|
| `account-service.yml` | Accounts, balances, positions and order history |
| `order-service.yml` | Order placement, execution and cancellation |
| `positions-service.yml` | Account positions |
| `shared-schemas.yml` | Common schemas such as `ErrorResponse` |

## Current specs

- **Trading API (Java):** [`../trading-api.json`](../trading-api.json), generated by springdoc from the running controllers. To refresh it after changing endpoints, start the backend (`docker-compose up -d kafka app`), then run `bash scripts/openapi/export-openapi.sh` from the repository root.
- **Auth service (NestJS):** [`../../auth-service.yml`](../../auth-service.yml), hand-written and checked against the service by its tests.
